# API reference

The C++ API reference is generated by [Doxygen](https://www.doxygen.nl/) from the comments in the source
code, and published with this site.

[:lucide-book-open: Open the API reference](../api/index.html){ .md-button .md-button--primary }

It lists the classes, functions and files of the client, the server and the engine. To make your code
appear with a description, see [Documenting C++ code](../contributing/documentation.md#documenting-c-code).

!!! note "Local preview"

    `zensical serve` does not generate the API reference. See
    [Previewing locally](../contributing/documentation.md#previewing-locally) to build the complete site,
    API reference included.
