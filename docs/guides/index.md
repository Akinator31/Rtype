# Guides

Step-by-step guides for common tasks in the client. They assume the project builds, see
[Build](../getting-started/build.md).

| Guide | What you will do |
|---|---|
| [Draw a sprite](draw-a-sprite.md) | Add an image to the assets, load it and draw it. |
| [Add a player action](add-a-player-action.md) | Add a new action, bind it to keys and buttons, and react to it. |

For how the systems used here work, see [Rendering](../architecture/rendering.md) and
[Input](../architecture/input.md).
