Detailed Description

A 32-byte ChaCha20-Poly1305 key, with which one side encrypts the datagrams it sends.

Each player has two: the client key and the server key, made by the master and sent over TLS (GAME_JOINED).

The key is secret: it is never logged, and its bytes are erased from memory once the last copy is destroyed. Copying a key is cheap: the copies share it.
