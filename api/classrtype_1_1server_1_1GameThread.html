Detailed Description

The simulation thread of an instance (ADR 0013): it owns the Simulation and steps it at a fixed rate, 60 ticks per second, whatever the network does.

The network thread hands it commands (players, inputs), and it hands back the result of each tick: they share nothing else.

rtype::server::GameThread game({}, [&](rtype::server::TickResult result) {
loop.post([&, result = std::move(result)] { host.publish(result); }); // to the network thread
});
game.start();
game.addPlayer(0); // from the network thread
game.receiveInputs(0, message.tick, message.inputs);
