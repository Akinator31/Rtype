Detailed Description

Calls a function after a delay, or at regular intervals, on the thread of an event loop: for timeouts and for the work a network thread does every tick.

rtype::network::Timer tick(loop);
tick.startRepeating(std::chrono::milliseconds(16), [&] { host.update(Clock::now()); });
rtype::network::Timer timeout(loop);
timeout.start(std::chrono::seconds(10), [&] { connection.close(); });
timeout.cancel(); // the handler will not be called

Every function can be called from any thread. The handler is called on the loop's thread, and never after cancel() or the destruction of the timer on that thread, even if it was already due. From another thread, a call already running may still end.
