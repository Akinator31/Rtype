Detailed Description

Networking shared by the client and the server: addresses, UDP and TCP sockets, and the event loop that runs them.

The sessions of the game over UDP (docs/protocol/game.md, sections 3, 7 and 8): a client connects to its game, both sides exchange messages, and the session ends on a disconnection or a timeout.

The encrypted datagrams of the game (docs/protocol/game.md, sections 2 to 4): a header in clear, the body encrypted with ChaCha20-Poly1305, and a tag that authenticates both.

Built on Asio, which never appears in these headers (ADR 0011).

Everything here works on bytes only, with no socket: it can be tested and fuzzed alone. A receiver uses it in this order, and drops the datagram silently at the first failure:

const auto header = rtype::network::parseDatagramHeader(datagram); // size, magic, version...
if (!header) return;
Session *session = sessions.find(header->session); // known session?
if (!session || !session->window.accepts(header->packetNumber)) return; // duplicate, replay, too old?
const auto body = rtype::network::openDatagram(session->peerKey, datagram); // forged or changed?
if (!body) return;
session->window.mark(header->packetNumber); // only once authenticated
handle(*body);

Built on the encrypted datagrams and the MessageChannel.

Like them, the classes here have no socket and no clock: they are given the datagrams received and the time, and send through a function. So they can be tested with a fake network, and used from a game loop as well as from a network thread. Each object must be used from one thread at a time.

◆ isValidText()

bool rtype::network::isValidText ( std::string_view  text)

Tells whether a text can be sent as a str8 field of the protocol: valid UTF-8, without ASCII control characters (0x00–0x1F and 0x7F).

Valid UTF-8 means the shortest encoding of each character (no overlong forms), no UTF-16 surrogates (U+D800–U+DFFF), and nothing above U+10FFFF. The length is not checked: each field sets its own range.

Use it to check a name typed by the player before sending it.
