Detailed Description

The packet numbers already received in a session, to drop the datagrams received twice: duplicated by the network, or replayed by an attacker who recorded them (docs/protocol/game.md, section 4).

It remembers the highest number accepted and the 256 before it. A number is accepted if it is higher, or within these 256 and not received yet. Older numbers are refused: a datagram this late is useless anyway.
