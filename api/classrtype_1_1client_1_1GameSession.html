Detailed Description

A game, as the game scene sees it: inputs go in, snapshots of the world come out (ADR 0015).

Offline, a LocalSession runs the Simulation in the client; online, a RemoteSession talks to the instance. The scene does not know which one it plays.

session.setInput(input); // the controls of the local player, once per frame
session.update(elapsed); // time goes by
for (const rtype::game::Snapshot &snapshot : session.takeSnapshots()) { /* draw the world */ }
