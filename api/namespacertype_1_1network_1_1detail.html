◆ lockCrypto()

std::unique_lock< std::recursive_mutex > rtype::network::detail::lockCrypto ( )

Mbed TLS is built without its own locks, so its global state (the PSA key store and random generator) must only be used by one thread at a time: every call into it holds this lock.

The first lock also initializes PSA Crypto.

Exceptions
std::runtime_errorif PSA Crypto cannot be initialized.
