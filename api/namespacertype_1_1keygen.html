Detailed Description

The key generation tool, r-type_keygen: makes the key pair the server proves its identity with (docs/guides/generate-the-server-keys.md).

The program itself only calls run(): the rest is here for the tests.

Writes the keys of an identity in a directory, which is created if missing: the private key in PrivateKeyFile, only readable by its owner on Unix, and the public key in PublicKeyFile.

Parameters
forceReplace the files already there. Without it, nothing is written if one of them exists.
Exceptions
std::filesystem::filesystem_errorif a file exists (std::errc::file_exists) or cannot be written: path1() is the file.
