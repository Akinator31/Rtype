Detailed Description

Everything that makes a kind of weapon: creating a new one is filling this and registering it in a WeaponRegistry.

Durations are in ticks (TickRate per second), distances in game units.

The firing mechanic: how the projectiles it fires move (physics).

It replaces the category of the projectile definition, so that one kind of projectile can be fired in different ways.
