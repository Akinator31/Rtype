Detailed Description

Why a session ended, given to the close handler.

Not called when the application closes the session itself.

Disconnected 

The peer sent DISCONNECT, with reason.

TimedOut 

Nothing valid received for SessionTimeout: the peer crashed or lost the network.

ConnectTimedOut 

The session never connected: no ACCEPTED for the client within ConnectTimeout (UDP is probably blocked), no CONNECT for the game within PendingTimeout.

Failed 

The peer stopped acknowledging the reliable messages: DISCONNECT (PROTOCOL_ERROR) was sent.
