Detailed Description

Loads the graphics resources of the game (textures, fonts, 3D models) and frees them when it is destroyed.

Each file is loaded once: loading the same path again returns the same handle. The game refers to resources by their handle only, which keeps raylib out of the rest of the code.

Graphics resources live in the window's graphics context, so the manager needs an open window and must be destroyed before it. Declare the manager after the window:

Window window;
ResourceManager resources(window, "assets");
const TextureId player = resources.loadTexture("sprites/player.png");
