◆ strength()

float rtype::input::Binding::strength ( const InputSource &  source,
float  deadZone 
) const

How strongly the input is held, from 0 (released) to 1 (fully pressed).

Keys, gamepad buttons and mouse buttons are 0 or 1. Axes are 0 inside the dead zone, then grow progressively up to 1, so that a stick slightly off-centre does not move anything.

Parameters
deadZonePart of the axis range that is ignored, between 0 and 1.
