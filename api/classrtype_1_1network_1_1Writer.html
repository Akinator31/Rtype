Detailed Description

Writes the fields of a message as bytes, following the conventions of the protocol: big-endian integers, no padding between fields (see docs/protocol/index.md, section 2).

rtype::network::Writer writer;
writer.writeU8(0x01); // type: HELLO
writer.writeU16(1); // version
writer.writeString("Pavel"); // name, str8
socket.send(address, writer.bytes());
