Detailed Description

The reliability layer of one session over UDP (docs/protocol/game.md, sections 5 and 6): numbers the datagrams, acknowledges those received, sends reliable messages again until they are acknowledged, delivers them once and in order, and measures the round-trip time.

It works on the bodies of the datagrams only, before encryption and after decryption, and is given the time: no socket, no clock of its own, so that it can be tested with a fake network. The session using it does:

// Sending, at least once per second (a heartbeat otherwise), and as long as there is something to send
channel.send(Snapshot::Type, snapshot, rtype::network::Delivery::Unreliable);
do {
const auto datagram = channel.next(now);
if (!datagram) { /* the channel failed: close the session */ }
socket.send(peer, sealDatagram(ownKey, {sessionId, datagram->packetNumber}, datagram->body));
} while (channel.hasMessagesToSend(now));
// Receiving
const auto header = parseDatagramHeader(datagram);
if (!header || header->session != sessionId || !channel.accepts(header->packetNumber)) return;
const auto body = openDatagram(peerKey, datagram);
if (!body) return;
if (const auto messages = channel.receive(header->packetNumber, *body, now)) {
for (const auto &message : *messages) { handle(message.type, message.payload); }
}

A channel fails when the peer stops acknowledging (more than MaxPendingReliable reliable messages waiting), or once every packet number was used. It then sends and receives nothing: the session must close.
