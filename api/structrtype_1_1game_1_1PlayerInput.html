Detailed Description

What one player does during one tick: the controls held, one bit each, exactly the byte of the protocol (docs/protocol/game.md, section 9.2).

It is data, not a device: the server receives it from the network, and the client makes it from the virtual gamepad of the engine (rtype::engine::Controls, fed by libs/input), so that the rules depend on neither raylib nor the bindings:

rtype::game::PlayerInput input;
input.set(rtype::game::PlayerInput::Up, controls.isDown(rtype::engine::Control::Up));
input.set(rtype::game::PlayerInput::Fire, controls.isDown(rtype::engine::Control::FaceDown));
simulation.setInput(slot, input);
