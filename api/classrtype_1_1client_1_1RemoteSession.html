Detailed Description

A game online: the session of the player with its game instance, over encrypted UDP (docs/protocol/game.md), with what GAME_JOINED gave (ADR 0015).

games.play(std::make_unique<RemoteSession>(loop, master.withPort(joined.udpPort), joined));
  • Inputs: once per tick (60 per second), it sends INPUT with the inputs of the last 8 ticks, newest first, so that a lost datagram loses no input. Each one is stamped with the tick the game should apply it at, estimated from the latest snapshot and the round-trip time (section 9.2).
  • Snapshots: the parts received and the destructions go into a RemoteWorld, and each world received into an Interpolation; takeSnapshots() gives, each frame, the world drawn 100 ms in the past, between the two snapshots around that time: the entities move at the frame rate, not 30 times per second.
  • The ship of the player is predicted: each input moves it at once, and each snapshot that has it reconciles the prediction with the game (Prediction). It is drawn where it is predicted, the rest where the interpolation draws it.
  • The end: DISCONNECT from the game, a timeout, or GAME_OVER; endReason() tells the player why.

The loop must be polled, by the game loop of the client.
