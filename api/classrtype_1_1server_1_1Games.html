Detailed Description

The games of the master (ADR 0013): one instance per game, started with Process, connected back on a local listener, and watched until it exits (docs/protocol/instances.md).

On the thread of the loop, used by the lobby.

rtype::server::Games games(loop, {.executable = rtype::server::currentExecutable()});
games.create({playerId, "Pavel"}, {"Bydo hunters", 4}, [&](rtype::server::Games::JoinResult result) {
// GAME_JOINED, or the error to answer
});

Definition: Process.cpp:62
  • Creating takes a free UDP port, draws a secret, starts the instance and waits for its READY: only then is the creator added and answered. No port: SERVER_FULL. No READY in time, or an instance that cannot start: GAME_START_FAILED, and the instance is killed.
  • Joining adds a player to a game that is ready: it gets a session and its keys, given to the instance (ADD_PLAYER) before the player (GAME_JOINED).
  • A game without players is shut down (SHUTDOWN (EMPTY)).
  • An instance that dies, or closes its connection, without GAME_OVER has crashed: its players are told (LEFT_GAME (GAME_CRASHED)). A game over is told too (LEFT_GAME (GAME_OVER)).
  • Its port is freed once the process has exited, killed if it does not within the stop timeout.
