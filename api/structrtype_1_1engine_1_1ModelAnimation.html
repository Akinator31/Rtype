Detailed Description

Plays an animation of the skinned Model of the entity, in a loop: the ModelAnimationSystem moves its time, the SceneRenderer poses the model before drawing it.

Play another one with switchModelAnimation(), which fades from the previous one, so that the model does not jump from a pose to the other.

const int idle = resources.getModelAnimation(model, "Idle");
ecs.addComponent<ModelAnimation>(ship, idle);
switchModelAnimation(ecs.getComponent<ModelAnimation>(ship), resources.getModelAnimation(model, "Move"));
