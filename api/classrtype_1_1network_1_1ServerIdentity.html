Detailed Description

What the server proves its identity with: its private key (ECDSA P-256), and the certificate it presents in the TLS handshakes, made from that key when the identity is created.

The certificate is self-signed and only carries the public key: the client does not check it against a certificate authority, it compares the key with the one it pins (KeyFingerprint).

const auto identity = rtype::network::ServerIdentity::load("server.key"); // the --key option
logger.info("Server key {}", identity.fingerprint().toHex());
