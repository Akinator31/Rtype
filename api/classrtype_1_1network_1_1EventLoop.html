Detailed Description

Runs the network: waits for data, connections and the end of sends, and calls the handlers given to the sockets.

Every socket belongs to one loop, and its handlers are only called from the thread that runs the loop, with run() or poll():

  • a network thread calls run(), which waits for events until stop() is called;
  • a game loop calls poll() once per frame, which handles what is ready and returns at once.

Sockets must be destroyed before their loop.

◆ run()

void rtype::network::EventLoop::run ( )

Handles events until stop() is called, waiting when there is nothing to do.

Returns at once if the loop is already stopped.

An exception thrown by a handler leaves run() and is given to its caller; calling run() again resumes the loop.

void rtype::network::EventLoop::stop ( )

Stops the loop: run() returns as soon as the current handler ends, and later calls to run() and poll() do nothing.
