Detailed Description

Draws the game: textures, text and shapes.

The game has a fixed size (1920x1080 by default), whatever the window: positions and sizes are always in game units, the same on every screen. The whole game area is always shown; a window of another shape shows more around it, on both sides, instead of black bars (see visibleArea() and computeVisibleArea()). Place the interface relative to the visible area, so that it follows the edges of the screen. The image is drawn at the resolution of the window, so it stays sharp on a large screen.

Everything is drawn between beginFrame() and endFrame(), in order: what is drawn last is on top.

Window window;
ResourceManager resources(window, applicationDirectory() / "assets");
Renderer renderer(window, resources);
const TextureId ship = resources.loadTexture("sprites/ship.png");
while (!window.shouldClose()) {
renderer.beginFrame();
renderer.drawTexture(ship, {100.0f, 540.0f});
renderer.endFrame();
}

◆ setColorFilter()

void rtype::render::Renderer::setColorFilter ( ColorFilter  filter)

Applies a colour filter to the whole image, interface included, for colour-blind players or players with low vision.

The filter is applied when the frame is shown, so the game draws with its normal colours. If the graphics card cannot run the filter, a warning is logged once and the image is shown unfiltered.

Draws a 3D model seen through a camera and lit by a light.

Models hide each other by depth, whatever their drawing order, except transparent ones, which must be drawn after what they cover. What is drawn afterwards in 2D is on top of them.

Parameters
positionWhere the origin of the model is, in world units.
rotationAxisAxis the model is turned around, and rotationAngle how much, in degrees.
scaleSize factor of the model.
tintColour multiplied with the model.
spinAngleHow much the model is turned around its own vertical axis (y), in degrees, before the rotation around rotationAxis: a tilted ring keeps its tilt while it spins.
Exceptions
std::logic_errorif no frame is started.

Poses an animated model at a time of one of its animations: the next draws of this model show this pose, until it is animated again.

Several entities sharing a model each pose it before being drawn. Animating a model without animations does nothing.
