Detailed Description

The game window, open for as long as this object exists.

The window is opened by the constructor and closed by the destructor (RAII). Only one window can exist at a time, as raylib supports a single window. Graphics resources (textures, fonts, shaders) need the window: create them after it and destroy them before it.

◆ setFullscreen()

void rtype::render::Window::setFullscreen ( bool  fullscreen)

Switches between a window and fullscreen.

Fullscreen is a borderless window covering the screen it is on, at the resolution of that screen: the screen keeps its video mode, so switching is instant and other windows are not disturbed. Leaving fullscreen restores the previous size and position of the window.
