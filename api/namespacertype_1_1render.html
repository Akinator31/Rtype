◆ ColorFilter

enum rtype::render::ColorFilter
strong

A filter applied to the colours of the whole image, for accessibility (see Renderer::setColorFilter()).

Enumerator
None 

Colours are unchanged.

Protanopia 

Helps players who do not perceive red (protanopia): the colours they confuse are shifted towards colours they can tell apart.

Deuteranopia 

Helps players who do not perceive green (deuteranopia), the most common colour blindness.

Tritanopia 

Helps players who do not perceive blue (tritanopia).

SimulateProtanopia 

Shows the image as a player with protanopia sees it: for the team, to check that the game stays readable.

SimulateDeuteranopia 

Shows the image as a player with deuteranopia sees it.

SimulateTritanopia 

Shows the image as a player with tritanopia sees it.

HighContrast 

Stronger contrast and saturation, for players with low vision.

Enumerator

◆ computeVisibleArea()

Rectangle rtype::render::computeVisibleArea ( Vector2  windowSize,
Vector2  gameSize 
)

Part of the game shown in the window, in game units.

The game always shows its whole area, from (0, 0) to gameSize, scaled as much as the window allows. When the window has another shape, the view extends around that area, on both sides, so that it fills the window without black bars: a 16:10 screen shows a 1920x1080 game from y = -60 to y = 1140. Game coordinates stay the same on every screen; only what is around the game area changes.

Parameters
windowSizeSize of the window, in pixels.
gameSizeSize of the game, in game units.
Returns
The visible area, in game units, or the game area if one of the sizes is empty, such as a minimised window.

◆ windowToGame()

Vector2 rtype::render::windowToGame ( Vector2  position,
Vector2  windowSize,
Vector2  gameSize 
)

Converts a position in the window, for instance the mouse pointer, into game units: the reverse of the scaling of computeVisibleArea().

A position near the edges of a window that is not of the shape of the game can be outside of the game area, for instance negative: check that it is between 0 and the game size before using it for gameplay.

Parameters
positionPosition in the window, in pixels.
windowSizeSize of the window, in pixels.
gameSizeSize of the game, in game units.
Returns
The position in game units, or (0, 0) if one of the sizes is empty.
