Detailed Description

Playing online (docs/architecture/client-online.md): the Online menu, where the player gives the server and its name, then the lobby of the server, with its games.

  • Connect opens a LobbyClient to the server, with the key of server.pub, next to the executable: a server without that key is refused.
  • The lobby lists the games: Create a game, Join one, Refresh, Disconnect. Joining plays a RemoteSession in the game scene; when the game ends, the player is back in the lobby.
  • What goes wrong is shown in a toast: the server cannot be reached, is not the expected one, the game is full...
