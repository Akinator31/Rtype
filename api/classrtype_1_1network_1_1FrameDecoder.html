Detailed Description

Splits a TCP stream into frames.

TCP delivers bytes in arbitrary pieces: a frame may arrive in several pieces, and several frames in one. The decoder keeps the bytes of the frame being received, and gives the frames as soon as they are complete:

decoder.feed(bytes);
while (const auto frame = decoder.next()) {
handle(frame->type, frame->payload);
}
if (decoder.failed()) {
connection.close(); // the peer does not follow the protocol
}

A size of 0, or above the maximum, makes the decoder fail as soon as the two bytes of the size are there, without waiting for the rest: a peer cannot make it keep more than one frame in memory. Once failed, the decoder ignores everything.

The decoder only works on the bytes it is given, with no socket: it can be tested and fuzzed alone.
