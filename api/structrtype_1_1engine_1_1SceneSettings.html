◆ overlay

bool rtype::engine::SceneSettings::overlay = false

The scene below stays visible, like a pause menu over the game. Otherwise, it hides what is below.

◆ hidesInterfaceBelow

bool rtype::engine::SceneSettings::hidesInterfaceBelow = false

With overlay, only the world of the scenes below stays visible, not their interface: a submenu over the 3D background of the main menu, without the buttons of the main menu.

◆ updatesWhenCovered

bool rtype::engine::SceneSettings::updatesWhenCovered = false
