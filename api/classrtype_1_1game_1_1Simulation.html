Detailed Description

One game of R-Type: its own ECS, the systems of the rules, and the players.

It knows neither the network nor the drawing: it takes the inputs of the players, steps one tick at a time, and gives a snapshot of the world (ADR 0015). The instances of the server and the client offline use the same class.

rtype::game::Simulation simulation;
simulation.addPlayer(0);
// Every tick (TickRate per second)
simulation.setInput(0, input);
simulation.step();
const rtype::game::Snapshot &world = simulation.snapshot();

It decides nothing about time: whoever uses it calls step() once per tick (a Timer on the server, an accumulator of the frame times on the client, a loop in the tests). The same inputs, in the same order, give the same snapshots: a game can be replayed, and the tests are exact.

Not thread-safe: use it from one thread, the simulation thread.
