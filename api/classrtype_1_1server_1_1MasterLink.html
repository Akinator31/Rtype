Detailed Description

The connection of an instance to its master, on 127.0.0.1 (docs/protocol/instances.md, section 2): it connects, presents itself with INSTANCE_HELLO, waits for CONFIGURE, then receives the players.

rtype::server::MasterLink link(loop, options.masterPort, {.id = options.id, .secret = secret},
{.onConfigure = [&](const ConfigureMessage &game) { link.sendReady(port); },
.onAddPlayer = ..., .onRemovePlayer = ..., .onShutdown = ...,
.onFailed = [&](const std::string &reason) { /* stop the game */ }});

The master and its instances follow the protocol, so anything else is a failure, after which the link is closed: a connection that cannot be opened, no CONFIGURE in time, a frame that does not decode, a message that is not expected (CONFIGURE twice, a player before CONFIGURE), or the master closing the connection.
