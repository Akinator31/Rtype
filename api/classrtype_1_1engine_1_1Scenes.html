Detailed Description

The stack of open scenes: home screen, game, pause menu over the game...

Every entity of a scene has a SceneMember. Scenes only keeps the stack: closing a scene removes it, and the Engine destroys its entities at the start of its next update (see takeClosedScenes()). Until then, they are neither visible nor updated. Systems ask the scenes what to do with an entity: receivesInput(), updates(), isVisible().

The Engine registers it as the first system: at the start of each update, it records which scene receives the input for the whole update. Otherwise the Escape press that closes the pause menu would, later in the same update, reach the game and open the menu again.

Scenes &scenes = engine.getScenes();
const SceneId game = scenes.open({.updatesWhenCovered = true});
const ecs::entity_t ship = engine.getEcs().createEntity();
engine.getEcs().addComponent<SceneMember>(ship, game);
