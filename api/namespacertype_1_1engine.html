Detailed Description

Client side of the engine: components and systems that connect the ECS to the rendering, the input and the interface.

The ECS itself (rtype::ecs) is shared with the server.

◆ Control

enum rtype::engine::Control
strong

A control of the virtual gamepad that the engine reads, whatever the device: the keyboard and every real gamepad are mapped onto it (see Controls).

A control has no meaning in itself: the game decides what each one does, for instance that FaceDown fires.

The buttons are named after their position, like input::GamepadButton.

◆ Navigation

enum rtype::engine::Navigation
strong

What the player can do in the interface.

Separate from the game actions: the same key can mean something else in a menu, like Escape, which opens the menu in game and goes back in a menu.

Enumerator
Up 

Focuses the previous widget.

Down 

Focuses the next widget.

Left 

Decreases the value of the focused widget (slider, choice, toggle).

Right 

Increases the value of the focused widget.

Confirm 

Activates the focused widget.

Back 

Goes back from the current scene.

Click 

Activates the widget under the mouse pointer.

Separate from Confirm: a click outside of the widgets must not activate the focused one.
