Detailed Description

The scenes of a game (ADR 0015): the game scene, which plays a GameSession through the GameSessionSystem, and the pause menu over it.

  • The game scene shows the starry sky, the world of the session, and a HUD with the lives and score of each player, in its colour.
  • Escape (or Start on a gamepad) opens the pause menu: Resume, or Leave the game. Offline, the game stops while it is open.
  • The game ends when the player leaves it or when its session is over: what to do then is given to play(), back to the main menu by default.
auto &sessions = ecs.registerSystem<GameSessionSystem>(ecs, engine.getScenes(), engine.getControls());
GameScenes games(engine, resources, metrics, style, sessions);
games.play(std::make_unique<LocalSession>()); // "Play" > "Solo"
