Detailed Description

template<typename Action>
class rtype::input::ActionMap< Action >

Turns the state of the input devices into game actions, through rebindable bindings.

The game defines its own actions, usually as an enum, binds each of them to one or more inputs, and only reads actions afterwards: the same code then works with a keyboard, a gamepad, or any other InputSource.

enum class Action { MoveUp, Shoot };
ActionMap<Action> actions;
actions.bind(Action::Shoot, Binding::key(Key::Space));
actions.bind(Action::Shoot, Binding::gamepadButton(GamepadButton::FaceDown));
// Once per frame, with the time elapsed since the previous frame
actions.update(devices, frameTime);
if (actions.wasPressed(Action::Shoot)) { ... }

Reads the input source and updates every action.

Call it once per frame, before reading the actions: they keep the state read here until the next update.

Parameters

Tells whether the action was pressed or repeated at the last update: true when it is pressed, then again at regular intervals while it is held (see setRepeat()).

For instance, holding Down in a menu moves the selection once, then keeps moving it after a short delay.

◆ heldDuration()

template<typename Action >
float rtype::input::ActionMap< Action >::heldDuration ( Action  action) const
inline

How long the action has been held, in seconds: 0 when it was just pressed, and when it is not held.

On the update where it is released (wasReleased()), it still gives how long it was held, so that a shot charged while holding the button can be fired on release.
