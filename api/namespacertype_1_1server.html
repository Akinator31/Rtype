Detailed Description

The messages between the master and its instances, on their local connection (docs/protocol/instances.md, section 4).

The server, r-type_server: the master that runs the lobby, or with --instance one game started by it (docs/architecture/server.md, ADR 0013).

Both sides use them: the instance now, the master with the lobby. Like the game messages, the encoders throw std::invalid_argument for a value the protocol forbids, and the decoders are pure: nothing for a malformed payload, never an exception.

Runs the event loop on this thread until the server stops, and handles the stop signals:

  • The first Ctrl+C or SIGTERM calls shutdown, which ends the work properly (tells the clients, waits for the games...) and calls loop.stop() once done.
  • A second signal, or the grace period without the loop stopped, stops the loop at once.
const bool clean = runUntilStopped(loop, [&] {
listener.close();
loop.stop();
});
return clean ? Success : Failure;
