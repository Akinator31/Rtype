Detailed Description

A game offline: the Simulation of libs/game runs in the client, for one player in slot 0 (ADR 0015).

The simulation steps exactly once per tick of game time, 60 times per second, whatever the frame rate: the frame times add up, and each full tick is one step, like the PhysicsStep. After a frame too long (a loading, a debugger), it steps at most MaxStepsPerUpdate times and forgets the rest: the game slows down for a moment instead of freezing to catch up.
