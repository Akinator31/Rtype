Detailed Description

template<typename Resource, typename Id>
class rtype::core::ResourceCache< Resource, Id >

Loads each resource once and keeps it until the cache is destroyed.

Resources are identified by a key, usually their file path: loading a key again returns the handle of the resource already loaded. Handles stay valid for as long as the cache exists. The cache does not know how to load a resource, the caller provides the loader, so it works with any kind of resource.

Template Parameters
ResourceType of the stored resources. It frees what it holds in its destructor.
IdHandle type returned for this kind of resource.
