Detailed Description

Animates a value of the entity from from to to in duration seconds.

The tween is removed when it ends, unless it goes back and forth.

ecs.addComponent<Tween>(button, Tween{.target = TweenTarget::Scale, .from = 1.0f, .to = 1.1f,
.duration = 0.2f, .easing = Easing::EaseOutBack});
