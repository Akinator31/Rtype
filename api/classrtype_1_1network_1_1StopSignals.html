Detailed Description

Calls a function when the program is asked to stop: Ctrl+C (SIGINT), SIGTERM (sent by kill, systemd or Docker), and on Windows Ctrl+Break and the closing of the console (SIGBREAK).

Each signal calls it again.

rtype::network::StopSignals signals(loop, [&](std::string_view signal) {
logger.info("{} received: stopping", signal);
loop.stop();
});
loop.run();
