Detailed Description

A short message shown in a corner of the screen for a few seconds, over every scene: "Settings saved", "Connection lost".

Created by Engine::showToast(), which is all a caller needs.

A toast holds only its message: its look comes from InterfaceStyle::toast, so that changing the look of every toast is done there. The ToastSystem places it, fades it in and out and destroys it; the SceneRenderer draws it.
