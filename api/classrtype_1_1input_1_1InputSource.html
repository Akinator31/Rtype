Detailed Description

Current state of the input devices: which keys and buttons are held, where the sticks are.

The game never reads devices directly: it reads actions from an ActionMap, which queries an InputSource. Devices reads the real keyboard and gamepads; tests use a fake source, and other sources (VR controllers) can be added without changing the game.

◆ takeTypedText()

virtual std::u32string rtype::input::InputSource::takeTypedText ( )
pure virtual

Characters typed since the previous frame, in the order they were typed, as Unicode code points.

Unlike keys, these are characters: they follow the keyboard layout and its modifiers (Shift, AltGr, accents), so typing "é" on a French keyboard gives "é". The characters are consumed: a second call in the same frame returns nothing. Read them through a TextInput, once per frame.
