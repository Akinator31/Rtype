Detailed Description

Owns the ECS, the events (ADR 0008), the scenes (ADR 0009) and the controls (the virtual gamepad).

At the start of each update, the engine destroys the entities of the scenes closed since the previous one, whoever closed them (a scene request, a menu button calling Scenes::close(), Back).

Named scenes are declared once with createScene(), then opened by name: switchScene() replaces every open scene, pushScene() opens one over them, popScene() closes the one at the top. Like a trigger, these requests take effect at the start of the next update(). Each named scene has two events, created with it: "<name>:open" and "<name>:close", triggered when the scene opens and closes.

Engine engine;
engine.createScene("game", {.updatesWhenCovered = true}, [](Engine &engine, SceneId scene) {
const ecs::entity_t ship = engine.getEcs().createEntity();
engine.getEcs().addComponent<SceneMember>(ship, scene);
});
engine.subscribeToEvent("game:open", physics, Reaction::Enable);
engine.switchScene("game");

◆ update()

void rtype::engine::Engine::update ( float  elapsed)

Runs one frame: updates the controls from the input source, if any, so that the whole frame reads the same state; destroys the entities of the closed scenes and applies the scene requests (which triggers the events of the scenes opened and closed), then the pending reactions, updates the ECS, and gives back their previous state to the systems changed by a Duration::Once reaction.

A permanent reaction cancels that restore.

Parameters
elapsedTime since the previous update, in seconds, given to every system.
