Detailed Description

A TCP connection that exchanges frames instead of bytes: each message arrives whole, with its type, in the order it was sent (docs/protocol/lobby.md, section 3).

The connection is a TcpConnection, or a TlsConnection to encrypt the frames: both work the same way.

rtype::network::FramedConnection server(std::move(connection));
server.start(
[](std::uint8_t type, std::span<const std::byte> payload) { /* one whole message */ },
[](std::error_code reason) { /* closed by the peer, lost, or invalid frame */ });
server.send(0x01, hello.bytes());

When the peer sends an invalid frame (size 0, or above the maximum), the connection is closed, and the close handler receives NetworkError::EmptyFrame or NetworkError::FrameTooLarge.

Every function can be called from any thread. The handlers are called on the loop's thread.
