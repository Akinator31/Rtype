◆ defer()

void rtype::ecs::Ecs::defer ( std::function< void()>  action)

Runs an action after the systems of the current update, or after those of the next one if called outside of an update.

Use it to change the world while a system goes through it: a button that opens a new screen would otherwise create entities, and reallocate the caches, while the system handling buttons is still reading them.
