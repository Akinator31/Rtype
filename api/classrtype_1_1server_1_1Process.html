Detailed Description

A program started by this one, on Linux and Windows: the master starts one per game (ADR 0013).

It hides reproc, the library that starts and stops it.

rtype::server::Process instance(rtype::server::currentExecutable(),
std::vector<std::string>{"--instance", "--id", "7", ...},
{.input = formatSecret(secret) + "\n"});
if (const auto code = instance.exitCode()) { ... } // it has exited: never blocks
instance.stop(); // asks it to stop, kills it if it does not

  • Its standard input receives ProcessOptions::input, then is closed: the program reads it, then the end of the stream. Nothing else can be written later, so a program that died early cannot break this one.
  • Its standard output and error are those of this program: the logs of the instances go with those of the master.
  • Destroying a Process stops the program if it still runs, like stop(): the master leaves no program behind, even on an exception.

Not thread-safe: use it from one thread, the event loop of the master.

◆ terminate()

void rtype::server::Process::terminate ( )

Asks it to stop: SIGTERM on Linux, Ctrl+Break on Windows.

A server ends its work first (ADR 0013), so wait for it with exitCode() or wait(). Does nothing once it has exited. On Windows, a program that has only just started may not receive it yet: stop() kills it after the grace.

Exceptions
std::system_errorif the request cannot be sent.
