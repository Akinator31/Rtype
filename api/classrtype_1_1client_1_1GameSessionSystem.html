Detailed Description

Plays the game session of the game scene (ADR 0015), each frame:

  1. the controls of the engine become the PlayerInput of the local player, an empty one when the scene does not receive the input (a menu is over it);
  2. the session updates, paused while a menu is over the scene;
  3. each snapshot becomes entities of the scene: one per entity of the game, created when it appears, moved, and destroyed when it is no longer in the world.
gameSessions.start(std::make_unique<LocalSession>(), scene); // when the game scene opens

The session stops by itself when its scene closes: the engine destroys the entities.
