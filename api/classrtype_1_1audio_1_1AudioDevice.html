Detailed Description

The audio output, open for as long as this object exists.

The output is opened by the constructor and closed by the destructor (RAII). If it cannot be opened, for instance on a computer without sound card, the game keeps running silently: a warning is logged and every sound is ignored. Only one device can exist at a time.

Create it after the Window, so that raylib's messages about the audio output go to the log too.
