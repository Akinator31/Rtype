Detailed Description

Predicts the ship of the local player online, so that it answers the controls at once, as offline: the game stays the one that decides, the client guesses what it will say (docs/architecture/client-online.md).

prediction.apply(tick, input); // each INPUT sent: the ship moves at once
prediction.reconcile(ship, snapshotTick); // each snapshot: where the game had it
prediction.advance(elapsed); // each frame
const auto drawn = prediction.position(); // where to draw it
  • Applying: each input sent moves the predicted ship by one tick, with the movement of the game (game::moveShip(), the same to the bit). The inputs are kept with their tick. A tick skipped when stamping repeats the previous input, as the game does.
  • Reconciling: a snapshot gives where the game had the ship at its tick, every input up to that tick applied. The prediction starts again from there and replays the inputs of the later ticks: when nothing was lost, it lands where it already was.
  • Correcting: when it lands elsewhere (an input lost, a wall the game saw first), the ship is not teleported: the gap is drawn and fades out over a few frames. A gap too large (the ship came back elsewhere) is not smoothed.
  • No ship (destroyed, waiting to come back): nothing is predicted; the game decides when it comes back.

Pure: no clock, no network.
