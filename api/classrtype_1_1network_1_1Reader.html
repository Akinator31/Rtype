Detailed Description

Reads the fields of a message from received bytes, following the conventions of the protocol: big-endian integers, no padding between fields (see docs/protocol/index.md, section 2).

The reader never reads past the end of the data. The first field that is missing or invalid puts it in an error state: that read and every later one return 0, false or an empty value, and error() tells what went wrong. So a decoder reads every field, then checks once, at the end:

rtype::network::Reader reader(payload);
const std::uint16_t version = reader.readU16();
const std::string name = reader.readString(1, 16);
if (!reader.finish()) {
logger.debug("HELLO dropped: {}", toString(reader.error()));
return std::nullopt;
}

Reading has no side effect besides the reader itself, and allocates no more memory than the data it reads: decoders built on it can be fuzzed.
