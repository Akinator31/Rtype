Detailed Description

Loads and plays the sound effects and the music of the game.

Sound effects (shots, explosions) are short and fully loaded in memory. The same sound can be played several times at once: each sound has a few voices, so that fast shots do not cut each other.

Music is long, so it is streamed from its file while it plays: call update() once per frame to keep the stream fed. Only one music plays at a time.

Each file is loaded once, like textures in the render library. The player needs an AudioDevice that outlives it; if the device is not available, everything still works but nothing is heard.

AudioDevice device;
AudioPlayer audio(device, applicationDirectory() / "assets");
const SoundId shot = audio.loadSound("sounds/shot.wav");
const MusicId stage = audio.loadMusic("music/stage1.ogg");
audio.playMusic(stage);
while (...) {
audio.update();
if (shooting) { audio.play(shot); }
}
